Profil peribadi dalam browser ini. Data setiap profil disulitkan dengan kata laluannya sendiri.

⚠️ Penyulitan tidak tersedia dalam browser ini.
Money Tracker memerlukan Web Crypto API untuk menyulitkan data, dan tidak akan menyimpan data tanpa penyulitan. Buka fail ini dalam versi terkini Chrome, Edge, Firefox atau Safari (terus sebagai fail, atau dari https:// / localhost). Tiada data dibaca, diubah atau dipadam.

⚠️ Data lama tanpa kata laluan

Data dari versi lama tracker ini belum disulitkan — sesiapa yang guna browser ini boleh membacanya. Lindungi data anda sahaja dengan kata laluan. Data lama tidak dipadam kecuali anda memilihnya.

Tentang keselamatan profil

Data setiap profil (termasuk gambar resit) disulitkan dengan AES-GCM menggunakan kunci yang dijana daripada kata laluan profil (PBKDF2-SHA256). Kata laluan dan kunci tidak disimpan.

Ini bukan keselamatan tahap pelayan: data kekal dalam browser dan peranti ini sahaja. Sesiapa yang boleh guna peranti ini masih boleh memadam data (contohnya dengan mengosongkan data browser), dan kata laluan yang lemah boleh diteka. Nama profil tidak disulitkan.

Kata laluan yang dilupakan tidak boleh dipulihkan. Simpan backup (menu profil → Backup disulitkan, atau Excel) di tempat selamat.
